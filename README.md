# Brigands

Jeu de plis multijoueur en ligne pour exactement trois joueurs.

## Lancer en local

```bash
npm ci
npm start
```

Ouvrez ensuite `http://localhost:3000`. Un joueur crée un salon privé et partage son code avec les deux autres.

## Tests

```bash
npm test
```

## Déploiement

Le projet contient un Blueprint `render.yaml` prêt pour Render. Consultez `DEPLOYMENT.md` pour les étapes et les limites de stockage des salons.
